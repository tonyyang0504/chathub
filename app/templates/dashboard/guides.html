WhatsApp
QR Code Authentication
1
Create a new bot in ChatHub and select WhatsApp as the platform. Enter your AI API key.
2
Click Start — a QR code will appear in a modal.
3
Open WhatsApp on your phone → Settings → Linked Devices → Link a Device.
4
Scan the QR code with your phone. The bot will connect and show your account info.
Tip: The session persists after server restart — no need to re-scan. Use Disconnect to unlink and scan a different account.
Telegram
Phone + Code Authentication (Real Account)
1
Go to my.telegram.org and log in with your phone number.
2
Click API development tools → Create an application → Copy API ID and API Hash.
3
Create a new bot in ChatHub, select Telegram, enter your AI API key.
4
Click Start → Enter API ID, API Hash, and your phone number → Click Connect.
5
Enter the verification code sent to your Telegram app. If you have 2FA, enter your password.
Tip: This connects your real Telegram account (not a bot). You'll see all messages. The session auto-reconnects on restart.
Discord
Bot Token Authentication
1
Go to Discord Developer Portal → Click New Application.
2
Click Bot in the sidebar → Click Reset Token → Copy the bot token.
3
Scroll down to Privileged Gateway Intents → Enable Message Content Intent and Server Members Intent.
4
Go to OAuth2 → Check bot scope → Under Bot Permissions, check Administrator (or specific permissions) → Copy the invite URL → Open in browser → Select your server → Authorize.
5
In ChatHub, create a Discord bot, click Start, paste the bot token.
Tip: The bot responds to @mentions in server channels and all DMs. Enable AI Response toggle for auto-replies.
Facebook Page
Facebook OAuth (One-Click Connect)
1
Create a new bot in ChatHub, select Facebook Page, enter your AI API key.
2
Click Start → Click Connect with Facebook.
3
Authorize ChatHub in the Facebook Login popup. Select the Facebook Page you want to connect.
4
Done! The bot auto-starts and receives messages sent to your Facebook Page via Messenger.
Tip: Messages must be sent via the Messenger app or messenger.com (not the Facebook page chat on facebook.com). The token is permanent and survives server restarts.
Note: This connects to a Facebook Page inbox only — not personal Facebook Messenger. The ChatHub administrator must have Messenger webhooks configured.
Instagram
Facebook OAuth (One-Click Connect)
1
Switch your Instagram account to a Professional account (Business or Creator): Instagram app → Settings → Account → Switch to Professional Account.
2
Link your Instagram to a Facebook Page: Instagram Settings → Account → Linked Accounts → Facebook.
3
Create a new bot in ChatHub, select Instagram, enter your AI API key.
4
Click Start → Click Connect with Facebook → Authorize.
Requirement: Instagram must be a Professional account (not personal) linked to a Facebook Page. The Instagram webhooks must be configured by the ChatHub administrator.
LINE
Channel Token Authentication
1
Go to LINE Developers Console → Create a Provider.
2
Create a Messaging API Channel (may require creating a LINE Official Account first).
3
Go to Basic Settings → Copy Channel Secret. Go to Messaging API → Issue Channel Access Token.
4
Set Webhook URL to your server URL + /webhooks/line → Enable Use webhook → Disable Auto-reply messages.
5
In ChatHub, create a LINE bot, click Start, enter Channel Access Token and Channel Secret.
Tip: Add the bot as a friend by scanning the QR code in the LINE Developers Console. Messages sent to the bot will appear in ChatHub.
Signal
signal-cli REST API + Phone Number
1
Install and run signal-cli REST API:
docker run -p 8080:8080 -v ./signal-data:/home/.local/share/signal-cli bbernhard/signal-cli-rest-api
2
Register a phone number (use a dedicated number, NOT your personal Signal):
curl -X POST http://localhost:8080/v1/register/+1234567890
3
Verify with the SMS code you receive:
curl -X POST http://localhost:8080/v1/register/+1234567890/verify/123456
4
In ChatHub, create a Signal bot, click Start, enter the API URL (http://localhost:8080) and your registered phone number.
Tip: Signal requires a dedicated phone number — you can't use the same number as your personal Signal app. Consider using a VoIP number or second SIM.
Note: signal-cli is an unofficial client. Signal may change their protocol at any time. Use Docker for easy updates.
Slack
Bot Token + App Token (Socket Mode)
1
Go to api.slack.com/apps → Click Create New App → Choose From scratch → Name it and select your workspace.
2
Go to Socket Mode (left sidebar) → Toggle Enable Socket Mode → Generate an App Token (name it "socket", add connections:write scope) → Copy the xapp- token.
3
Go to OAuth & Permissions → Under Bot Token Scopes, add: chat:write, files:write, users:read, channels:read, im:read, groups:read, im:history, channels:history.
4
Go to Event Subscriptions → Toggle Enable Events → Under Subscribe to bot events, add: message.im, message.channels, message.groups, app_mention.
5
Go to Install App → Click Install to Workspace → Authorize → Copy the Bot Token (xoxb-).
6
In ChatHub, create a Slack bot, click Start, enter both tokens (Bot Token + App Token).
Tip: Slack uses Socket Mode (WebSocket), so no webhook URL or ngrok is needed. The bot responds to @mentions in channels and all DMs. Invite the bot to channels with /invite @botname.
Tinder
Auth Token (Unofficial API)
1
Open tinder.com in Chrome and log in to your account.
2
Open Developer Tools (F12) → Go to the Network tab.
3
Use Tinder (swipe, open a match, send a message) → Look for requests to api.gotinder.com.
4
Click on any request → Headers tab → Find and copy the X-Auth-Token value.
5
In ChatHub, create a Tinder bot, click Start, paste the auth token.
Warning: This uses an unofficial API. Tokens may expire. There's a risk of account restrictions. Use a proxy if the API is blocked in your region.
Bumble
Phone + SMS Authentication (Unofficial API)
1
Create a new bot in ChatHub, select Bumble, enter your AI API key.
2
Click Start → Enter your phone number (the one registered with Bumble).
3
Enter the SMS verification code sent to your phone.
4
The bot connects and starts receiving messages from your matches.
Warning: This uses an unofficial API. There's a risk of account restrictions. In heterosexual matches, women must message first (Bumble's rule).
LinkedIn
OAuth Authentication
1
Go to LinkedIn Developer Portal → Click Create App.
2
Fill in app name, LinkedIn Page, logo → Submit. Go to Auth tab → Copy Client ID and Client Secret.
3
Under OAuth 2.0 settings, add your redirect URL: https://your-server/auth/linkedin-callback.
4
Request access to the Messaging API product under the Products tab (requires approval).
5
In ChatHub, create a LinkedIn bot, click Start, enter your OAuth credentials.
Note: LinkedIn Messaging API has strict rate limits (100 requests/day). Access requires LinkedIn approval. Best suited for low-volume professional messaging.
iMessage
BlueBubbles Server (macOS Required)
1
You need a Mac running 24/7. Download and install BlueBubbles on the Mac.
2
Open BlueBubbles → Complete setup → Enable the REST API under Settings → API/Webhooks.
3
Note the Server URL (e.g., https://your-mac.ngrok.io) and Password from BlueBubbles settings.
4
In ChatHub, create an iMessage bot, click Start, enter the BlueBubbles server URL and password.
Tip: BlueBubbles requires the Mac to stay on with Messages app signed in. Use a Mac Mini as a dedicated server. Supports DMs, group chats, reactions, attachments, and read receipts.
Note: iMessage only works with Apple devices. Non-Apple contacts will receive SMS (green bubbles) which may not be supported by all carriers via BlueBubbles.
WeChat
QR Code Authentication (Planned)
1
Create a new bot in ChatHub, select WeChat, enter your AI API key.
2
Click Start → A QR code will appear (similar to WhatsApp).
3
Open WeChat on your phone → Scan the QR code to log in.
Note: WeChat integration is currently planned and not yet fully implemented. WeChat has strict API policies and may require a WeChat Official Account for automation.
WhatsApp Business API
Official Meta Cloud API (Webhook-based)
1
Go to Meta Business Suite → Create or select a Business account.
2
Go to Meta Developers → Create a new app → Select Business type → Add the WhatsApp product.
3
In WhatsApp > API Setup: Add a phone number and verify it. Copy the Phone Number ID and generate a Permanent Access Token (via System User in Business Settings).
4
In WhatsApp > Configuration: Set the Webhook URL to https://your-server/webhooks/whatsapp-business. Set the Verify Token to chathub_whatsapp_business. Subscribe to the messages field.
5
In ChatHub, create a bot with WhatsApp Business API platform. Click Start, enter the Phone Number ID and Access Token.
Tip: Use a System User permanent token (not the temporary one from API Setup). The temporary token expires in 24 hours. System User tokens are permanent.
Note: WhatsApp Business API has a 24-hour messaging window — you can only send messages within 24 hours of the customer's last message. After that, you need to use approved Message Templates.
